TRACKAMAZONAS TALLER 3 - COMANDOS Y UTILIDAD
PowerShell en la raíz del proyecto. No ejecutar todo como un script.

1. ENTORNO
python -m venv .venv
Crear un Python aislado.

.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Instalar versiones. Hacerlo antes de la exposición.

2. PIPELINE
.\.venv\Scripts\python.exe main.py
50.000 originales + defectos, Bronze/Silver/Gold, ocho consultas y benchmark.
Con entorno activado: python main.py.

.\.venv\Scripts\python.exe main.py --rows 500000 --repeats 9
Ensayo comparable con la evidencia de referencia. Reservar para ensayo previo.

.\.venv\Scripts\python.exe main.py --root "ensayo_nuevo" --rows 50000
Aislar un ensayo. Los comandos de consulta deben usar --root ensayo_nuevo.

3. RESULTADOS
